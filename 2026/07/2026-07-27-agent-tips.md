# 🏗️ Agent 的「批量重构」超能力 —— 一次改十个文件不手抖

> 2026-07-27 | daily agent tips

你有没有遇到过这种情况——

产品说:"把 `user` 改成 `customer`，全局替换一下。"

你心想:"简单，Ctrl+Shift+H 搞定。"

结果半小时后：
- `userId` 变成了 `customerId` ✅
- `getUserProfile` 变成了 `getCustomerProfile` ✅
- 但 `user.js` 文件名没改 ❌
- 导入路径还是 `../models/user` ❌
- 数据库表名还是 `users` ❌
- 某个隐蔽的字符串 `'user_not_found'` 没变到 ❌

**纯文本替换 =  Russian Roulette（俄罗斯轮盘赌）。**

今天聊两个 Agent 工具的「安全批量重构」姿势 👇

---

## 技巧一：Claude Code 的「描述即重构」🎯

Claude Code 有个隐藏大招：**你描述意图，它自己找文件、自己改、自己验证。**

**不是简单的字符串替换，是语义级重构。**

**用法：**
```
你：把项目里的 "user" 概念统一改成 "customer"，包括：
     - 变量名、函数名、类名
     - 文件名和目录名
     - 数据库相关的字符串（表名、字段名、错误码）
     - 别忘了改完之后跑一遍测试
```

Claude Code 会：
1. 🔍 先 `find` + `grep` 摸清全局有哪些地方涉及
2. 📝 制定重构计划（给你看一眼）
3. 🔧 按文件逐个修改（不是瞎替换，是 AST 级别的重命名）
4. ✅ 改完自动跑 `npm test` 或你指定的验证命令
5. 🧐 发现测试挂了，自己看报错，继续修

**关键点：** 你可以在开头加一句 **"如果测试挂了，先修测试再停"**，它就会进入「不达目的不罢休」模式。

> 💡 进阶用法：复杂重构前先让它 `git commit`，改崩了随时 `git reset`。Claude Code 甚至会提醒你这个操作。

## 技巧二：Cursor Composer 的「跨文件生成」🎼

Cursor 的 Composer（Cmd+I 或 Ctrl+I）不只是改当前文件——**它可以同时改多个文件，还能创建新文件。**

**场景：** 你要给项目加一个「用户权限检查中间件」，涉及：
- 新建 `middlewares/auth.ts`
- 修改 `src/app.ts` 注册中间件
- 修改 `routes/user.ts` 加上权限注解
- 修改 `types/index.ts` 补充类型定义

**传统做法：** 切来切去，改一半忘了到哪了。

**Composer 做法：**
```
你：给所有 /api/admin/* 路由加上 JWT 权限校验中间件。
     需要：
     1. 新建 auth 中间件文件
     2. 在路由文件里应用
     3. 别忘了 401/403 的错误处理
```

Composer 会：
1. 在左侧列出所有要改的文件 📋
2. 每个文件显示 diff（绿色新增、红色删除）
3. 你点 "Accept All" 一键应用，或逐个挑着接受

**最香的是：** 你可以跟它讨价还价——
> "中间件里再加上 role 检查" → 它自动更新相关文件
> "错误返回用中文" → 批量改所有错误文案

像有个实习生帮你改代码，**你还能随时喊停、随时追加需求。**

## 今日冷知识 🧊

Windsurf Cascade 也有类似的「多文件编辑」能力，而且它的特色是**自动运行命令验证**——改完代码后，Cascade 可以自己跑 `npm run build`，看到 TypeScript 报错，然后继续修，直到编译通过。

适合那种"你只管提需求，剩下的它自己折腾到能跑"的懒人模式。
