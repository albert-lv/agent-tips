# Agent 技巧日签 · 2026-07-28

## 今日主题：让 Claude Code 当你的「Shell 翻译官」

还记得第一次打开终端，面对黑底白字的那种"我是谁我在哪"的感觉吗？

Claude Code 有个被低估的神功能——`/terminal`（或者直接输命令不用前缀）。它不只是执行命令，而是把你的**人话翻译成 Shell**，再把 Shell 的输出翻译回人话。

---

### 💡 技巧一：自然语言操作文件

不用背 `find` 的十万个参数，直接说：

```
> 找出过去 7 天修改过的所有 Python 文件，看看哪些 import 了 numpy
```

Claude 会自动翻译成：
```bash
find . -name "*.py" -mtime -7 -exec grep -l "import numpy" {} +
```

然后问你"要执行吗？"——按个回车就完事。

更狠的是，你可以让它**解释**一个你从 StackOverflow 复制来的神秘命令：

```
> 这个命令在干嘛？tar -czvf backup.tar.gz --exclude='node_modules' .
```

它会给你逐段拆解，告诉你 `-czvf` 每个字母的含义，还会提醒你 `"排除 node_modules 是明智的，不然你的备份会肥成球。"`

---

### 💡 技巧二：直接扔截图，让它看报错

这是很多人不知道的黑魔法：

把报错截图拖到终端（或粘贴图片路径），Claude 能直接读取图片内容。不用你手动敲那段 500 行的 TypeScript 报错，直接：

```
> 这个报错什么意思？（附上截图）
```

它能看到红色高亮的错误行、堆栈跟踪，甚至认出这是 Next.js 的惯犯错误——然后给你修好。

---

### 🎯 一句话总结

**`/terminal` 不是替代你学命令行，而是降低试错成本。** 敢问了，就敢用了；敢用了，就慢慢记住了。

明天的你，会感谢今天那个敢对 AI 说"帮我看看这个报错"的自己。
