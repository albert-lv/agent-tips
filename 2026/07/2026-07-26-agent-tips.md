# 🤖 Agent 每日技巧 — 2026-07-26

## 今日主题：让 Agent "记得" 你说过的废话

你有没有遇到过这种情况：跟 Claude Code 聊了半小时项目结构，换了个窗口或者重启之后，它一脸茫然地问"请问这是什么项目？"

**不是它失忆，是你没给记忆。**

### 技巧一：用 `.claude/CLAUDE.md` 做 Agent 的"入职手册"

Claude Code 会自动读取项目根目录下的 `CLAUDE.md`（或 `.claude/CLAUDE.md`），把它当成"系统提示"的一部分。你可以在里面放：

- 项目技术栈和架构决策
- 常用的 npm/pnpm 命令别名
- "我们团队不用 xxx，用 yyy" 的偏好设定
- 甚至"我是后端苦手，改 API 前先问我"这种个人习惯

**效果：** 每次启动 Claude Code，它就已经"知道"你们团队的潜规则，不用反复交代。

> 💡 同理，Cursor 支持 `.cursorrules`，Kimi Code 会读项目里的 `README.md` 和 `.kimi/config.md`。各家名字不同，思路一样：**给 Agent 写份常驻记忆。**

---

### 技巧二：Windsurf Cascade 的 "@" 上下文拖拽

Windsurf 的 Cascade 有个很骚的操作：在侧边栏的文件树里，**直接把文件/文件夹拖到聊天框**，它会自动转成 `@file` 或 `@folder` 引用。

但这还不是最香的。

**隐藏玩法：** 你可以把**终端输出的错误信息**直接拖进 Cascade，它会自动读取终端上下文，不用你手动 copy-paste 一堆报错。

> 适合场景：编译爆错、测试挂掉、lint 狂吼的时候，一把拽过去，Cascade 直接开始修。

---

## 一句话总结

Agent 工具越来越像人 —— **它们能记住的，只有你明确告诉它们的。** 花 10 分钟写个 `CLAUDE.md` 或 `.cursorrules`，能省下未来几十次"我们项目用 pnpm"的解释成本。

下次启动 Agent，它应该说的是"又见面了"，不是"你是谁"。
