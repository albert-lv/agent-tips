# 09-27 — Agent 的「行车记录仪」—— 改了啥、花了啥、卡在哪，都要有回放可看

## 🤔 信任危机现场

Agent 干活越久，你心里越没底：

- 它一口气改了 8 个文件，你到底想看看 diff，但翻 git status 像翻垃圾桶
- 装了一堆 skill，每个都在悄悄吃上下文 token，哪个值回票价完全不知道
- 想问个「这功能到底怎么配」，结果为了查文档切出终端，回来思路全断

昨天的 tips 讲了「怎么把方向掰回来」，今天讲另一半：**怎么全程看得见它干了啥**。看不见就管不住，管不住迟早翻车。

## 🛠️ 技巧一：Claude Code —— `/diff` 实时面板 + `/skill-doctor` 成本审计

这俩都是 9 月上半月（v2.1.251–269）悄悄上线的，低调但实用。

**`/diff`**：打开一个实时 diff 面板贴在对话旁边，Claude 每改一处，面板立刻刷新。不用等它跑完再 `git diff` 考古——**边看边审**，发现不对当场打断（正好用上昨天的 steering 技巧，闭环了）。

```text
> /diff
```

**`/skill-doctor`**：列出你装的每个 skill 在上下文里实际占了多少 token、被调用了多少次。装的时候雄心壮志「这技能一定能用上」，三个月后一看：好家伙，2000 token 的提示词，半年调用 1 次。

```text
> /skill-doctor
```

> 💡 用法建议：`/skill-doctor` 的输出别只当报表看，**当清理清单看**。调用次数为 0 或 1 的 skill，删掉或者改成按需加载（菜单里现点现用），上下文预算立刻宽裕一截。技能不是收藏品，是用具。

## 🛠️ 技巧二：Kimi Code —— `/check-kimi-code-docs`，查文档不出终端

Kimi Code 内置了一个文档问答 skill（最近几个版本加入）：

```text
> /check-kimi-code-docs 配置子代理的模型池
```

它直接查官方文档回答你，**还带出处链接**，不用你自己去翻文档站。CLAUDE.md 怎么写、某个报错码啥意思、会员权益有哪些，这类「产品使用问题」再也不用离开终端切浏览器——切走一次，回来 agent 状态、终端上下文、刚才的思路全要重新加载，隐形成本高得离谱。

顺手再安利一个同期的 `/copy`：把上一条 AI 回复**整个复制到剪贴板**。以前 agent 给了 200 行你觉得不错的方案，手动选中像给猫洗澡，现在一个命令的事。

## 📝 今天记住这个

| 场景 | 解法 |
|---|---|
| 想看 agent 正在改哪些文件 | Claude Code `/diff` 实时面板，边看边审 |
| 想知道哪个 skill 在吃 token | `/skill-doctor`，低调用率的直接清理 |
| 忘了某个功能怎么配 | Kimi Code `/check-kimi-code-docs`，带出处不出终端 |
| 想把 AI 的长回复复制走 | `/copy` 一键上剪贴板 |

一句话总结：**放任 agent 黑盒狂奔是「盲驾」，开上行车记录仪才叫上路。** 🚗
