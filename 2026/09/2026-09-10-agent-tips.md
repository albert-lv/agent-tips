## 今日主题：Claude Code 的 "@" 魔法——让 AI 精准阅读，不瞎猜

**一句话总结：用 `@` 点名文件，比说一万句 "请你参考 xxx" 好使一万倍。**

---

### 技巧 1：Claude Code 的 `@` 精确制导

你是不是也遇到过这种情况——你跟 Claude Code 说 "帮我改一下那个 utils 文件里的函数"，结果它一通操作猛如虎，改的是另一个 utils 文件？

**解法：在提示词里直接用 `@` 引用文件/文件夹。**

```
@src/utils/helpers.ts 里的 formatDate 函数有点慢，帮我优化一下，
参考 @src/utils/constants.ts 里的日期格式定义。
```

Claude Code 会自动把这些文件塞进上下文，**指哪打哪**，不会再出现 "我以为你说的是那个文件" 的惨案。

**进阶玩法：**
- `@folder/` → 把整个文件夹丢进去，适合 "帮我看看这个项目结构"
- `@file.ts:10-20` → 只引用文件的 10-20 行，省 token 又精准
- 配合 `/add` 命令 → 永久把某个文件加入会话上下文，不用每次 @

### 技巧 2：Kimi Code 的 "自动补全思维链"

Kimi Code 有个挺隐形但很爽的功能：**它会自动把你的碎片化指令补全成完整的执行计划**。

比如你说：
```
把这个函数重构一下
```

Kimi Code 不会直接动手，而是先输出一个类似这样的思维链：
```
1. 分析当前函数的职责和依赖
2. 提取重复逻辑为子函数
3. 更新相关调用点
4. 运行测试验证

确认执行吗？ (Y/n)
```

**这意味着啥？** 你可以用更短的指令获得更可控的结果，不用写一堆 "请分步骤、请先分析、请别乱改" 的 prompt engineering。
