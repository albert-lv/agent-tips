# Agent Tips — 2026-09-14

## 🎯 今日技巧：让 Agent "先想后做"

Claude Code 和 Kimi Code 这类 agent 工具都有一个通病：你一说"改这个"，它立刻就开始敲键盘，结果改到一半发现思路不对，又回撤重来。效率打折，token 还白烧。

**解法：养成让它先出方案的习惯。**

试试这样开口：

> "先别动代码，帮我分析一下这个 bug 的可能原因，列出三种假设和验证步骤，我们再决定怎么修。"

你会发现 agent 突然变"稳"了——它会先整理上下文、列出排查路径、甚至帮你写出测试用例来验证每个假设。等你拍板了，它再动手，命中率直线上升。

**进阶版：** 在 Claude Code 里可以直接说 `/plan`（或让它"制定一个修改计划"），它会生成一个 step-by-step 的 todo list，你可以逐条审核、跳过、或者调整顺序。这不只是省 token，更是让你从"被 agent 带着跑"变成"你带着 agent 跑"。

## 🧠 冷知识：Windsurf 的 "Cascade Memory"

Windsurf 有个不太起眼但很实用的功能：它的 Cascade 会把当前会话里的关键上下文（比如你反复强调的编码规范、项目结构约定）自动记住，后续对话里即使你没重复提，它也会按这个风格来。

**用法：** 在会话开头花 30 秒告诉它你的偏好——"我们用 2 空格缩进"、"优先用 TypeScript 严格模式"、"不要加没必要的注释"——后面整个会话它会自己保持这个风格，不用你一遍遍纠正。

这比每次新开 chat 都从头调教省心太多了。
