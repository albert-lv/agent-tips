# Agent Tips — 2026-09-16

## 🎯 今日技巧：两个 Claude Code 会话，终于会「私聊」了

多开工作流的朋友一定经历过这个：一个会话在查日志格式，另一个在写 parser 测试，两边进度全靠你人肉搬运——「它说时间戳可能带时区偏移，你记得加个 case」。

2026 年 8-9 月的版本更新给 Claude Code 加了**跨会话消息**，以后不用当传话筒了：

- `ListAgents`：发现同机可达的其他会话
- `SendMessage`：按名字把一段文字直接发给那个会话

关键是**怎么发**。不是复制粘贴聊天记录，而是发「可执行的交接」：

❌ "它修好了" —— 这句话对面没法接
✅ "parser 已支持时区偏移，请在 parser-tests 里补一个 offset timestamp 的 case" —— 对面看完就能干活

配套还有个 `notify_when_idle`：让主会话盯着另一个本地会话，它一闲下来就通知你。配合 `claude remote-control`，手机上的 Code 页卡还能看到每台设备的会话卡片，出门也能戳开继续跑。

**实操三件套：**
1. 用 `/rename` 给会话起清楚的名字，比如 "log-analysis"、"parser-tests"，别用自动生成的含糊标题
2. 分工时明确边界：谁查资料、谁写码、谁跑测试
3. 两边都要改代码的话，配 git worktree 隔离文件，最后合并验收

## 🧠 冷知识：/cost 不只看钱，还能给你的 prompt cache「把脉」

9 月新版 `/cost` 多了个 Prompt Cache 行：缓存命中率、miss 次数、warm/cold 状态，甚至**告诉你 miss 的可能原因**——是工具定义变了？系统 prompt 改了？还是太久没聊缓存过期了？

两个小提醒：
- `hit_ratio` 是**输入 token** 的缓存命中占比，不是请求命中率，别读歪了
- 这个统计只覆盖**主会话**，子 agent 的开销不在这里面，跑 agent 军团时记得分开算

下次跑长任务，顺手瞄一眼这条线：如果你的工具列表天天变，缓存永远热不起来——稳的工具定义才是真省钱。
