# 09-23 — 该省省，该花花 —— Agent 的「模型编队」，杂活别再麻烦教授了

## 🧾 先算一笔账

你有没有想过：Agent 每次帮你跑测试、读日志、整理 import，用的都是同一个「最强大脑」？

这就像请教授来帮你贴发票——不是不能贴，是贵得离谱。

模型圈有个公开的秘密：**旗舰模型和轻量模型的价差能到 10 倍以上**，而「读个文件总结一下」这种活，轻量模型一样干得漂亮。所以 2026 年的进阶玩法，已经从「选哪个模型」进化成了「**怎么编队**」。

## 🧠 技巧一：Claude Code —— 主力打硬仗，杂活交给 Haiku

Claude Code 一直支持多模型混编，只是默认配置下所有活都挤在同一个脑子上：

- **`ANTHROPIC_SMALL_FAST_MODEL` 环境变量**：指定一个 Haiku 级别的快模型，专门给标题生成、上下文压缩这类辅助任务用——它们以前可都是偷偷吃你好模型额度的
- **自定义子代理（`.claude/agents/*.md`）的 `model:` 字段**：给侦察兵、文档员这类分身单独指定便宜模型。子代理本来就有独立上下文，脏活累活全包，配上便宜模型就是**双倍省**——主 Agent 的 token 预算和脑子都保住了
- **`/model` 随时换挡**：日常用 Sonnet 足够，遇到架构设计、疑难 bug 再切 Opus。像自动挡切运动模式，不用下车换车

> 💡 参考编队：主 Agent = Sonnet（日常）/ Opus（硬仗）；子代理 = Haiku（搜索、总结、格式化）。同样预算，杂活吞吐量翻好几倍。

## 🦾 技巧二：Kimi Code —— 子 Agent 模型池，官方把「副将」直接发给你了

Kimi Code 在 0.42 版本干了件很贴心的事：**子 Agent 模型池（`[secondary_model]`）默认开启**，实验开关直接退役。

意思是：你喊一声「后台把这堆文件的 import 整理一下」，主 Agent 继续陪你聊架构，子 Agent 拿着自己配置的模型在后台吭哧吭哧干，干完回来交报告。快、便宜、还不打扰你。

顺路安利同版本一个「省眼神」更新：**已完成的工具调用默认折叠成一行摘要**，想看细节按 `Ctrl-O` 展开。以前跑一轮测试刷 800 行日志的日子结束了——上下文清爽了，Agent 走神也变少了。

## ⚠️ 反面教材：该花不花，返工更贵

编队不是一味的省。两个场景千万别抠：

- **架构设计 / 技术选型**：便宜模型给你个「能跑但半年后爆炸」的方案，返工成本是 token 钱的一万倍
- **疑难 bug / 复杂重构**：这种需要长推理链的硬仗，旗舰模型一次想对，胜过便宜模型五次试错

**省钱的上限不是「全用便宜的」，是「贵的只出现在刀刃上」。**

## 📝 今天记住这个

| 场景 | 解法 |
|---|---|
| 标题生成、压缩总结等辅助任务 | Claude Code 配 `ANTHROPIC_SMALL_FAST_MODEL`，别让教授贴发票 |
| 翻代码、跑搜索的侦察活 | 子代理 + 便宜模型，脏活不进主上下文 |
| 后台批量杂活（Kimi Code） | `[secondary_model]` 模型池默认开启，喊一声就开工 |
| 输出刷屏眼神累 | `Ctrl-O` 折叠/展开工具调用，上下文清爽 |
| 架构设计 / 疑难 debug | 别省！切旗舰，一次想对胜过五次返工 |

一句话总结：**编队编得好，同样的 token 预算，别人养一个 Agent，你养一个编队。** 🎯
