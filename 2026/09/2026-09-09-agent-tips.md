# 2026-09-09 Agent Tips

## Claude Code：用 `/undo` 和 `/redo` 当后悔药，但更好用

Claude Code 最近把 undo/redo 做成了**时间线级别的后悔药**——不只是撤销上一步，而是可以**在对话历史里任意点来回跳转**。

**实用技巧：**

1. **`/undo N`**：撤销最近 N 步操作。比如 `/undo 3` 直接回到三步之前的状态，不用一条一条删。
2. **`/redo`**：当然也能重做回来。
3. **最骚的是**：undo 之后，你可以**在旧分支上继续走新路**。相当于在对话里开了个**平行宇宙**，而不是简单回退。想 A/B 测试两种方案？ undo 到分叉点，试另一条路，两边结果都能保留。

> 💡 以前最怕的就是"这句 prompt 不错，但上一步改崩了"。现在你可以放心让 Claude 试，走错了 `/undo` 回来，像 git rebase 一样把对话历史修干净。

## Cursor：Agent 模式的「规则库」比提示词更管用

很多人用 Cursor 的 Agent 模式还在写一大段 prompt 告诉它"你要怎么做"。

Cursor 其实支持 **`.cursorrules`** 文件——放在项目根目录，里面写你的编码规范、技术栈偏好、禁止事项。Agent 每次执行前都会读这个文件，相当于给它戴了一副"老花镜"，不用每次提醒。

**示例 `.cursorrules`：**

```
- 优先使用 TypeScript，不用 any
- 组件用函数式，hooks 放顶部
- 不要生成测试代码，我自己来
- 修改文件前先告诉我改哪几行
```

**进阶玩法：**
- 不同项目放不同的 `.cursorrules`，Cursor 自动识别当前目录的配置
- 配合 `.cursorignore` 排除不需要 AI 处理的文件，减少 token 浪费和幻觉

> 🫠 以前每次都要在 prompt 里写"用 TypeScript""别写测试"，现在丢进规则库就完事。Agent 不是不会，是提醒太多了它会忘。

---

**今日 takeaway：** Claude Code 的时间线跳转让"试错"不再可怕，Cursor 的规则库让"重复提醒"变成"一次配置"。都是那种——用了就回不去的功能。
