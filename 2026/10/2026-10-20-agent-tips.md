# 10-20 — Agent 的「桌面登陆战」：Kimi Code Desktop 1.1.0 上岸 Linux，CLI 不再是唯一入口

## 🤔 你的 Agent 还困在终端里吗

先把时间线摆一下：9/17 Kimi Code Desktop 发布，但只有 macOS 和 Windows——Linux 用户眼巴巴看了快一个月。上周四（**10/14**）**v1.1.0** 一发入魂：

- 🐧 **Linux 版正式落地**：x86_64 架构直接给足 AppImage / deb / RPM 三种包，Ubuntu、Debian、Fedora 全覆盖；
- 📱 **远程控制**：设置里开启后，手机扫个二维码就能遥控本机 Agent 干活（任务和工具还是在电脑上跑，手机只是方向盘）；
- 🌳 **右侧栏新增文件树**：浏览工作区文件、点击直接预览，`Cmd/Ctrl + Shift + E` 快速开关；
- 🗣️ **实验性「进展更新」**：Agent 在回合内主动播报短进展，不用干瞪着等它憋大招；
- ⌨️ **`kimi app` 命令**：终端里敲一下就唤起桌面端，在当前（或指定）目录开新会话。

同时行业背景也在这周发酵：Cursor 被 SpaceX 收编、Devin 吞掉 Windsurf 之后，**各家都在抢「桌面入口」**——Claude Code Desktop 上周也连发定时任务（10/13）和并行任务窗口（10/14）。终端党 vs 图形党的战争，正式进入白热化。🔥

## 🛠️ 技巧一：Linux 安装一条龙，别再用网页版凑活

三种姿势任选，按你的发行版来：

```bash
# Ubuntu / Debian：直接上 deb
sudo dpkg -i kimi-code-desktop_1.1.0_amd64.deb

# 跨发行版通用：AppImage，免安装
chmod +x kimi-code-desktop_1.1.0.AppImage && ./kimi-code-desktop_1.1.0.AppImage

# Fedora / RHEL 系：RPM
sudo rpm -i kimi-code-desktop_1.1.0.x86_64.rpm
```

装完第一件事：登录后直接吃满三件套——**打开项目 → 对话改代码 → 右侧文件树 + diff 逐行审**。桌面端和 CLI 共用同一套 Agent 能力和账号额度，不存在「图形版缩水」的问题。审批提示也在，「始终询问 / 必要时询问 / 完全自动」三档权限随便切，YOLO 选手请自重。⚠️

**远程控制**顺手也开了：设置 → 远程控制 → 拿手机扫二维码。下班地铁上发现 CI 挂了？手机指挥家里电脑的 Agent 修 bug，真正做到「人没到，活先干」。（9 月 CLI 的 `kimi rc` 我们 10/04 讲过，现在是桌面端原生支持，不用命令行了。）

## 🛠️ 技巧二：`kimi app` + 进展更新——CLI 与 GUI 无缝换轨

最被低估的更新其实是这个一行命令：

```bash
kimi app          # 在当前目录唤起桌面端，开新会话
kimi app ~/projects/agent-arena   # 指定目录直接开工
```

典型场景：你在终端里用 CLI 干了一半，发现要改的东西太多、想边看 diff 边审？**不用复制路径、不用手动开软件**，一条命令原地跳车，会话上下文接着用。

配合实验性「进展更新」（设置 → 实验室，开启后对新会话生效），Agent 长任务不再「黑箱憋大招」——每推进一小步就播报一行，干等焦虑直接减半。等待期间发的消息还会**立即送达**、插进当前轮次，不用等它转完圈。

```
你: 把这个模块重构一下，跑完测试告诉我
Agent: ✓ 已读完 12 个相关文件
Agent: ✓ 正在修改 cache 层…
Agent: ✓ 跑测试中（3/47）…
你: 对了顺手把日志加上          ← 立即送达，不打断后台任务
```

## 📋 今天记住这个

| 场景 | 一句话操作 |
|---|---|
| Linux 装桌面端 | AppImage / deb / RPM 三选一，官网下载即装 |
| 手机遥控电脑 Agent | 设置 → 远程控制 → 扫码，人在外面活在家干 |
| CLI 跳到 GUI | `kimi app [目录]`，一行唤起桌面端新会话 |
| 长任务不黑箱 | 设置 → 实验室 → 开「进展更新」，新会话生效 |
| 快速翻文件 | `Cmd/Ctrl + Shift + E` 开关文件树，点击即预览 |

**一句话总结**：Kimi Code 现在桌面端、CLI、IDE 插件三形态共享同一套能力和额度——按场景切入口，不再「为了用 GUI 迁工作流」。Linux 用户这周的等待，值了。🐧
