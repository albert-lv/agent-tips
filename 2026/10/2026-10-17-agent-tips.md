# 10-17 — Agent 的「改装车间」：官方终于开放魔改接口，桌面版还能自己多开打工

## 🤔 这个礼拜，Claude Code 偷偷换了个物种

如果你这几天没关注官方动态，这里帮你补齐——过去两周 Claude Code 连放三招：

- **10/01**：**Mods 系统**正式上线（v2.1.287+ 默认开启）——可以用 JavaScript/TypeScript 函数直接改写 Claude Code 的行为和界面，官方内置的 `/diff` 都已经 mod 化了；
- **10/13**：Claude Desktop 1.1.5368+ 支持**定时任务**，每天的定型业务可以让它自己到点上班；
- **10/14**：桌面版新增**并行任务窗口**——多个任务自动各开独立工作画面，互不抢戏。

一句话：那个「终端里的聊天框」，正在长成一台能定时启动、多开并行、还能自己换皮肤的**全天候工作站**。今天就拆两个最该立刻上手的。🔧

## 🛠️ 技巧一：Mods——用 JS/TS 给 Claude Code 写「外挂皮肤」

以前想定制 Claude Code，只能写 Hooks（只能拦命令）或装插件（只能加工具）。Mods 是第三层：**你的函数直接挂到 Claude Code 的事件流上**——工具调用前、prompt 发送时、界面渲染中，都能插一脚。每个 mod 只能干三件事之一，但组合起来很野：

- **看**：旁路观察，不干预（比如盯着上下文用量画个仪表盘）；
- **改**：改写后继续放行（比如给每个 prompt 自动注入项目背景）；
- **挡**：自己回答并终止这次调用（比如危险命令直接按住）。

和 Hooks 的关键区别：**mod 跑在 Claude Code 内部**，能持有状态、能画 UI、能加斜杠命令——`/diff` 就是官方用 mod 重写的。最骚的是，你可以直接用自然语言让 Claude 给你写 mod：「给我写一个 mod，每次提交前显示本次改动的文件数」。

**30 秒上手**（官方 playground 带了三个现成样品，不用写一行代码）：

```bash
git clone https://github.com/anthropics/claude-code-playground.git
cd claude-code-playground/claude-code/mods
claude --plugin-dir ./token-weather   # 上下文用量变成"天气预报"画在 prompt 上方
```

三个 sample 各司其职：`token-weather`（上下文余量可视化）、`blast-radius`（高危命令按住并展示影响面）、`replay-theater`（`/replay` 逐帧回放上一轮的每次编辑）。试完想常用，再正式 `claude plugin install` 进插件目录。

⚠️ **安全红线**（企业用户划重点）：mod 在**你的权限下、沙箱之外**运行。团队环境请先定三件事——限定来源、`claude plugin validate` 审中身、`allowManagedModsOnly` 锁死名单，再开放给队员。个人玩则无所谓，自己的电脑自己负责。💀

## 🛠️ 技巧二：桌面版「多开打工」组合拳（10/13 + 10/14 新功能）

把 Claude Desktop 更新到最新版，你会得到两个新按钮级能力：

**① 定时任务（10/13，v1.1.5368+）**：让 Claude 每天固定时间自动执行例行活——晨报生成、依赖巡检、日志摘要。配合 10-10 讲过的 Routines 思路，把「重复劳动」从待办清单上划掉，它到点自己干。

**② 并行任务窗口（10/14）**：当 Claude 在桌面版里同时接多个任务，会**自动为每个任务开独立工作画面**——左边窗口在重构模块 A，右边窗口在调研库 B，两边上下文完全隔离、互不串味。不用再手动开两个终端、`cd` 到不同目录、祈祷它们别抢同一个文件。

**心法**：并行窗口是「多开隔离」的终极形态，正好接上 10-12「Agent 的指挥部」那条——任务之间**没有依赖才并行**，有依赖就乖乖排队。3 个窗口各干各的杂活，比 1 个窗口排队快得多，但每个窗口都别把上下文喂太饱（10-11 的保鲜术依然适用）。

## 🥚 彩蛋：让 Claude 当你的「改装师傅」

Mods 最香的姿势不是自己写，而是**让 Claude 写**：直接在会话里说——

> 帮我写一个 mod：每次我要跑 `rm -rf` 或 `git push --force` 时，
> 先弹一个确认卡片，列出受影响的文件数和最近 3 条 commit。

它会现场生成 mod 给你试。⚠️ 一个小坑：这种「会话内生成」的 mod 存在**会话级临时位置**，刷新就没。觉得好用就立刻复制进自己的插件目录持久化——不然下次开机，你的定制皮肤就「失忆」了（对，就是那个熟悉的回旋镖）。🪃
