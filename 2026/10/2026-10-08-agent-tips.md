# 10-08 — Agent 的「手感调校」：一句话存进家规，状态栏一眼看清家底

## 🤔 两个「就差一点点」的日常

**日常一：** Agent 又给你生成了一份 `package-lock.json`——而这个项目全家都用 pnpm。你叹了口气，把「回头把『用 pnpm』加进 CLAUDE.md」写进待办。然后就没有然后了。下周，lock 文件再次准时出现。记忆的敌人从来不是记性差，是**「记录」这个动作太麻烦**。

**日常二：** 长会话跑了俩小时，你开始感觉它有点「健忘」。它到底还剩多少上下文？现在是哪个模型在干活？分支切没切对？——你什么都看不见，只能盲猜，直到它开始胡说八道。

昨天让 Agent 自己上路验收了（10-07 试驾员），今天调调你自己的**驾驶坐姿**。两个零成本小动作：一个让「记家规」快到不会忘，一个让关键信息常驻眼皮底下。🎛️

## 🛠️ 技巧一：`#` 一句话速存家规 —— 想到就写，别等「回头整理」

CLAUDE.md 这东西，10-01 我们学过用 `/memory` 查看编辑，但说实话——「退出会话 → 打开文件 → 找到位置 → 保存」这条链路，足够把 90% 的「顺手一记」劝退。

Claude Code 其实给了一个输入框直连 CLAUDE.md 的快捷键：

```
# 这个项目用 pnpm，不要生成 package-lock.json
```

在输入框里以 `#` 开头敲这句话，回车——它直接追加进家规，**不离开当前会话，不打断手头任务**。下次会话启动，这句就是 Agent 的出厂设置。

### 三个值得当场 `#` 的瞬间

- **被同一个坑绊倒第二次时**：别忍，当场写进去。「改了 X 之后必须重启 dev server」这种话，写一次，省一辈子。
- **Agent 误解你意图但你懒得解释时**：`# 我说「简单处理」的时候意思是先跑通，不是省略错误处理`——偏好的沉淀比规则的堆积值钱。
- **项目里的「隐形约定」**：哪些目录不能动、哪个脚本是摆设、跑测试前要先起 docker——这些没人写进 README，但 Agent 每踩一次坑，你就该记一条。

> 和 09-15 的自定义命令是同一个哲学的两端：commands 沉淀「反复要做的动作」，`#` 沉淀「反复要记的规矩」。一个防手累，一个防心累。

## 🛠️ 技巧二：statusLine 状态栏 —— 让模型、分支、上下文用量常驻眼皮底下

Claude Code 输入框上方有一行状态栏，默认只显示个目录，属于「占着位置没干活」级别。它其实完全可定制——settings.json 里加一个 `statusLine`：

```json
{
  "statusLine": {
    "type": "command",
    "command": "~/.claude/statusline.sh"
  }
}
```

Claude Code 会把当前会话信息（模型、目录、花费等）以 JSON 通过 stdin 喂给你的脚本，显示什么你说了算。一个极简版：

```bash
#!/bin/bash
input=$(cat)
model=$(echo "$input" | jq -r '.model.display_name // "?"')
dir=$(echo "$input" | jq -r '.workspace.current_dir // "?"' | xargs basename)
branch=$(git branch --show-current 2>/dev/null)
echo "🤖 $model  📁 $dir  🌿 $branch"
```

效果：每轮对话前一眼看清——**现在是哪个模型在干活、在哪个仓库的哪个分支**。配合 09-23 的模型编队（杂活用快模型、硬仗上大模型），切了模型之后再也不用猜「它到底是谁」。

### 为什么值得花这五分钟

- **长会话的「油量表」**：把 cost 或 token 用量也渲进状态栏，上下文快满时你比 Agent 先知道——主动 `/compact`（08-12）永远比被动失忆强。
- **多开时的防串台**：三个会话三个仓库，窗口标题全靠蒙？状态栏写明目录 + 分支，切换不再心跳加速。
- **排障时先看仪表**：它行为突然变蠢，先瞄一眼状态栏——模型是不是被限流降级了？（呼应 10-06 体检思路：先看仪表，再掀引擎盖。）

> 顺手一个零成本搭配：提问前加 **"think" / "think hard" / "ultrathink"** 按需调思考档位。架构评审用 ultrathink，改个文案就别浪费——推理预算和上下文一样，该省省该花花（呼应 09-23）。

## 📌 今天记住这个

| 场景 | 一句话操作 |
|---|---|
| 又被同一个坑绊了 | 输入框敲 `# 这个坑的教训`，回车，当场入家规 |
| 项目有隐形约定 | 别攒着，想到一条 `#` 一条 |
| 想知道现在是哪个模型 | statusLine 把模型名挂上状态栏 |
| 感觉 Agent 开始健忘 | 状态栏看用量，主动 `/compact` |
| 难题 / 杂活分流 | `ultrathink` 给硬仗，改文案别浪费思考档 |

> 工具用久了，比「会不会」更重要的是「顺不顺手」。家规写入快 10 秒，关键信息少猜 3 次——手感这东西，调校前以为是玄学，调校后回不去。🎮
