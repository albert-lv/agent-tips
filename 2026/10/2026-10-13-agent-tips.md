# 10-13 — Agent 的「图纸会审」：动磁盘之前，先把方案给我看看

## 🤔 一个经典的「说干就干」翻车现场

你丢给它一句：「给登录加个记住设备的功能。」它回了一声「好的」，然后当场开工——改认证中间件、动数据库、顺手重构了它看不顺眼的 session 模块，八个小时后递给你一个 +900/-300 的 diff，其中有三处改动你根本没让它做，还有一处把别人的 API 语义改崩了。

你血压上来的那一刻，它还挺委屈：「这些改动都是实现这个功能必需的呀。」

不是它不行，是你**跳过了流程**。工地上没人看一眼草图就直接浇筑混凝土，都是先出图纸、会审、签字，然后才动工。Agent 也一样——**Plan Mode（计划模式）就是那道图纸会审**。🧱

## 🛠️ 技巧一：Claude Code Plan Mode——按 Shift+Tab 两次，世界进入只读

状态栏那行小字不只是装饰，它是**权限模式**：Claude 每次动手前要不要问你，由它决定。按 **Shift+Tab** 在模式间循环：

```
default → acceptEdits → ⏸ plan mode on →（auto）→ 回到 default
```

连按两次 Shift+Tab，状态栏出现 `⏸ plan mode on`，它就进入了「只读勘察期」：能读文件、能跑只读命令摸底，但**一个字节都写不到你的磁盘上**。

### 三种进入姿势

| 姿势 | 什么时候用 |
|---|---|
| 会话中 **Shift+Tab** ×2 | 聊到一半发现这活不小，临时上会审 |
| 输入 **`/plan`**（v2.1.0+） | 同上，手残党友好 |
| 启动时 `claude --permission-mode plan` | 早知道是硬仗，开门就递图纸 |
| `.claude/settings.json` 里设 `"permissions": {"defaultMode": "plan"}` | 高危仓库（支付/迁移/生产配置）的常驻默认值 |

### 会审流程

1. 它只读探索、出方案：改哪些文件、按什么顺序、边界情况是什么；
2. 方案出来你不满意？**Ctrl+G** 把方案丢进外部编辑器直接改，改完回来说「按这个来」；
3. 点头批准后自动切出 plan mode，开始施工——从你签字那一刻起它才有锤子。

### 省钱彩蛋：`--model opusplan`

贵模型出图纸、便宜模型施工：`claude --model opusplan` 用 Opus 做规划阶段、Sonnet 做执行阶段。就是 09-23「模型编队」和 10-12「杂活外包」那套思路的官方封装——脑子用贵的，手用快的。

## 🛠️ 技巧二：Kimi Code Plan Mode——图纸写成文件，多方案摆上桌给你点

Kimi Code 这边同样有 Plan 模式：**Shift-Tab** 或 **`/plan on`** 进入，启动时也能 `kimi --plan`。但它的做法更「工程」——**方案是落盘的**：

### 五步流水线

1. **只读勘察**：Glob/Grep/Read 摸代码库，拿不准就派 explore 子代理（只读规划专员）；
2. **设计**：收敛出推荐方案；
3. **写图纸**：方案写进计划文件（`~/.kimi/plans/` 下，这是规划模式下**唯一允许写**的文件——想偷跑都没门）；
4. **提交审批**：`ExitPlanMode` 把方案端到你面前；
5. **你批了才动刀**。

### 多方案点选，选了锁死

如果它觉得有两三条路都能走，计划里会摆 2~3 个候选方案，审批时直接以选项形式呈现，标好 `(Recommended)`。**你点哪个，它严格执行哪个**，不存在「我都批了 A 它顺手按 B 施工」的惊悚剧情。被驳回也不慌：改计划文件、重新提交，对话上下文不丢。旧图纸作废用 `/plan clear`。

### 两个反直觉的安全细节

- **Yolo 也不豁免方案审批**——平时爱开 `/yolo` 图省事的，图纸这道闸照样给你把着；只有 Afk 全自动档才都免审批。省的是点「允许」的手，省不掉签字。
- 每次批准完，它回到执行态时系统还会补一句「工具权限已全部恢复」的提醒——图纸阶段和施工阶段，它自己分得门儿清。

## 🧭 心法：一句话判官

那什么活该上会审、什么活直接干？判据就一条：

> **如果你能用一句话说清期望的 diff，就不用规划；说不清，就先规划。**

| 活儿 | 姿势 |
|---|---|
| 改个 typo、修个明确的 bug | 直接干，上会审才是浪费 |
| 跨多文件的功能 / 大型重构 / 动数据库 | Plan Mode，图纸签完再动工 |
| 只要调研、不要改动 | Plan Mode 天然只读，白嫖一个「只许看不许摸」的勘察期 |
| 方案以后还想翻 | 让它存成 Markdown 文件——滚动记录里的计划，会话一关就蒸发（和 10-11「怕丢的先存盘」一个理） |

## 📌 今天记住这个

| 场景 | 一句话操作 |
|---|---|
| 会话中临时上会审 | Claude：Shift+Tab ×2；Kimi：Shift-Tab 或 `/plan on` |
| 高危仓库常驻图纸模式 | `.claude/settings.json` → `defaultMode: "plan"` |
| 方案要动刀子改 | Ctrl+G 丢进外部编辑器，改完再批 |
| 想省 token | `claude --model opusplan`：贵脑出图，快手施工 |
| 好几个方案摆在面前 | Kimi 审批时直接点选，选谁就锁死谁 |
| 旧图纸作废重来 | `/plan clear`，别拿昨天的图纸盖今天的楼 |

> 会审不是不信任它，是把返工的钱花在动笔之前。今天开始，凡是「一句话说不清」的活，先让它交图纸，你签字，它动工。🫡
