# 10-10 — Agent 的「排班表」+「门铃」：到点自己上班，完工主动喊人

## 🤔 两个当「人形闹钟」的瞬间

**瞬间一：** 你教会了 Agent 干一个周期活——每天早上扫一遍 CI、出份日报。然后从那天起，**你**成了那个每天记得喊它上班的人。定时任务靠人肉触发，约等于没定时。

**瞬间二：** 一个长任务丢后台跑了 40 分钟。你每隔 5 分钟 Alt-Tab 回去瞄一眼：好了吗？好了吗？——等下，到底谁是员工，谁是监护仪啊。

09-22 我们搭过「穷人版夜班」（`claude -p` + 系统 cron），能用但糙：没人喊你，输出还得自己捞。今天给它升级成正规军：**正牌排班表** + **完工门铃**。两边工具都是现成的，就差你知道。⏰

## 🛠️ 技巧一：正牌排班——让 Agent 自己记得上班

### Kimi Code：内置 cron，说出来就能排

Kimi Code 从 0.5 版起就内置了定时任务，标准 5 段 cron 语法，直接在对话里让它排班：

- 「每个工作日早上 9 点，扫一遍这个仓库的 CI 状态，生成一份日报」
- 「每 5 分钟检查一次部署，挂了立刻喊我」
- 「30 分钟后提醒我回来继续这个重构」

到点它自己启动干活，定时提醒在终端里有独立样式渲染，不会埋在对话流里找不着。

> 冷知识：你现在每天早上 08:42 收到的这篇 tips，背后就是同一个思路——把「记得干活」从人脑卸载给 cron。效果你每天都在验收。

### Claude Code：Routines，夜班的官方正装

穷人版的官方升级版在 claude.ai/code 网页版：**Routines**——模板化的云代理，三种触发方式：

| 触发方式 | 能干啥 |
|---|---|
| ⏰ 定时计划 | 每天 9 点扫仓库、周一出周报，云端全新环境跑完直接交付 |
| 🐙 GitHub 事件 | 新 issue 打了 bug 标签 → 自动复现 → 评论根因；PR 收到 review 意见 → 自动修 |
| 🔌 API 调用 | 你自己的系统出事了 → HTTP 一脚踹醒它，带着模板上下文上岗 |

每次触发都是干净的云环境 + 可复用模板，结果直接落回 GitHub。配上 `/autofix-pr`（终端一句话开自动修复 PR），「夜班干活 + 早会材料」一条龙。

### 三档排班，按需选用

| 方案 | 成本 | 适合 |
|---|---|---|
| `claude -p` + 系统 cron（09-22 穷人版） | 免费但糙，输出自己捞 | 本地小活、先试试水 |
| Kimi Code 内置定时任务 | 零配置，说句话就排好 | 日常提醒、周期巡检 |
| Claude Routines（云端） | 网页版功能 | 要交付物的正经夜班、团队流程 |

## 🛠️ 技巧二：完工门铃——别再每隔 5 分钟去探视

### Claude Code：手机推送，Agent 自己会叫人

手机上装 Claude app、和 Claude Code 配对（就是 10-04 那台「遥控器」的同款链路）之后：长任务跑完、或者 Claude 卡在某步等你拍板，**手机直接弹推送**。跑过 `claude remote-control` 的机器还会在手机 Code 标签页里显示成设备卡片——出门在外也能掏出手机看它在干嘛，顺路批个权限。

从此长任务的标准动作从「反复切窗探视」变成「丢后台 → 等门铃」。

### 全工具通用：让它自己敲铃（一行命令的事）

没有官方推送的工具，或者懒得配？收尾咒语里加一句就行：

```bash
# macOS：任务结束后运行
afplay /System/Library/Sounds/Glass.aiff

# Linux：任务结束后运行
notify-send "Agent 收工" "任务完成，速来验收"

# 万能终端铃（macOS / Linux 通吃）
printf '\a'
```

人话版：「全部干完之后，自己制造点动静」。Agent 收工会老老实实敲一下——你尽管去倒水，铃响了再回来验收。

> 桌面党进阶：Claude Code 的 hook 输出支持 `terminalSequence` 字段，可以让 hook 在任务结束时发桌面通知、改窗口标题、响铃——自动化门铃，连咒语都省了。

## 📌 今天记住这个

| 场景 | 一句话操作 |
|---|---|
| 每天固定活不想让脑子记 | Kimi Code：「每个工作日 9 点生成日报」，内置 cron 直接排 |
| 要正经夜班 + 交付物 | claude.ai/code 的 Routines：定时 / GitHub 事件 / API 三种触发 |
| issue 进来想自动复现 | Routines 挂 bug 标签触发，根因自动评论到 issue |
| 长任务跑着想安心摸鱼 | Claude app 配对收推送，完工 / 卡壳手机叫你 |
| 啥工具都能用的门铃 | 收尾咒语加「结束后 `printf '\a'`」，它自己敲铃 |

> 好的协作不是「我看着它干活」，而是「它自己记得上班，干完自己喊我」。排班表配上门铃，这次真正下班的人是你。🔔
