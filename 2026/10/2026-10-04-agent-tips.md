# 10-04 — Agent 的「风筝线」：人出门了，活还能牵着走

## 🤔 周日下午的经典 dilemma

假期最后一天，你出门前给电脑上的 Agent 派了个大活：「把这周积压的 12 个 issue 过一遍。」

刚上地铁，手机震了——Agent 停下来等你批准一个 `git push`。你看着微信干着急：回家还有 40 分钟，它就在那儿**干等你**。

另一边的戏码是：你干脆让子代理在后台跑个长任务（全量回归测试 / 大规模重构 / 数据迁移），跑到 59 分钟，啪——被一刀掐死。原因很离谱：**子代理开的后台命令，原来有一小时的「宵禁」**。

今天两个技巧，一个给你一根**风筝线**（人走了线还在），一个把**宵禁拆了**。

## 🛠️ 技巧一：Kimi Code 远程控制 —— 手机就是你电脑的「远程窗口」

`kimi rc` 这个远程控制功能 9 月初刚转正式（不再需要实验开关），用法简单到不像话：

```bash
kimi rc
```

终端会打印一个二维码 + 访问链接（`https://code-rc.kimi.com/devices/<设备ID>/`）。手机扫码 → 登录**同一个 Kimi 账号** → 选这台机器，完事。

已经在 CLI 会话里？敲 `/remote-control`（别名 `/rc`），当前会话直接交给远程界面。

### 远程能干啥？

基本等于你把电脑屏幕揣进了兜里：

- **看进度**：执行步骤、工具调用、子 Agent 状态，实时同步
- **批权限**：文件修改、Shell 执行的确认请求，手机上直接批准/拒绝
- **继续指挥**：追加指令、改方向、随时叫停
- **开新任务**：本地技能和插件远程照常用

### 三个必须知道的边界

1. **任务始终在你电脑上跑**。手机只是窗口——文件、凭证、环境全在本机，关掉浏览器任务照常跑，重新打开链接视图就回来了。
2. **链接别乱发**。拿到链接 + 同账号登录 = 能控制你这台机器。它是入口，不是分享物。
3. **本机进程不能死**。`kimi rc` 是前台进程，终端一关远程就断（锁文件 `~/.kimi-code/server/rc.json` 里有 pid，丢了终端就 `kill <pid>` 清理再重开）。

> 💡 微信里打不开链接？微信内置浏览器会拦，点右上角「···」→「在浏览器中打开」即可。扫码后同理。

## 🛠️ 技巧二：Claude Code 子代理后台命令，1 小时宵禁解除

2.1.282（9 月 22 日）的一条不起眼更新，解了很多人的痛：

> 移除了子代理启动的后台命令的一小时时限——现在它们和主会话一样，跑直到退出或被手动停止。

以前：子代理跑 `pytest` 全量回归 / 大规模数据迁移，59 分 59 秒被掐，前面全白跑。
现在：任务多长它跑多长。

搭配姿势：主会话派活 → 子代理后台跑长任务 → 你 `kimi rc`（哦不对，这边是 Claude Code）出门 → 手机上…… 等等，Claude Code 用户怎么办？

**平替方案**：`claude -p` 无头模式 + SSH 到 VPS 跑（09-22「夜班模式」那期聊过），或者干脆开两个工具配合：重活扔给 Kimi Code 远程盯，Claude Code 干需要精细打磨的活。工具是死的，组合是你的。

## 📌 今天记住这个

| 场景 | 一句话操作 |
|---|---|
| 出门了要盯家里的 Agent | `kimi rc`，手机扫码，登录同账号 |
| 已在 CLI 会话里想切远程 | `/rc`（`/remote-control`） |
| 终端丢了要清理远程实例 | `cat ~/.kimi-code/server/rc.json` 拿 pid → `kill <pid>` |
| 微信里打不开远程链接 | 「···」→「在浏览器中打开」 |
| 子代理长跑被 1 小时掐头 | 升级 Claude Code ≥ 2.1.282，宵禁已拆 |
| 链接能不能发群里 | 不能。它是你机器的遥控器 |

> 周日收尾，给 Agent 也放个「风筝」——线在你手里，它在天上飞。🪁
