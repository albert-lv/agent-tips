# 10-01 — Agent 的「换装间」+「笔记本」：输出风格一键切换，经验自动沉淀

## 🤔 你有没有这两种时刻

**时刻一：**你在高铁上用手机热点让 Claude Code 干个活，它非要给你写三段开场白、两层小标题、外加一句「希望这个方案对您有帮助」。流量在燃烧，你只想让它闭嘴干活。

**时刻二：**同一个坑，上周刚踩过，这周换了个 Session，Agent 又义无反顾地跳了进去。你气急败坏地重新解释一遍，心里默念：「我不是教过你了吗？」——不，你教过**上一个它**。

今天两个小技巧，一个管「嘴」（输出风格），一个管「脑」（记忆沉淀）。正好国庆长假第一天，给 Agent 也换个新装、补个笔记。

## 🛠️ 技巧一：`/output-style` —— 给 Agent 换「输出皮肤」

Claude Code 默认是个「热情的话痨」，但很多时候你需要的只是一个字：**结果**。

```text
/output-style
```

输入这条命令，你会看到内置的几个风格，常用的两个：

| 风格 | 效果 |
|---|---|
| **Default** | 完整推理 + 解释 + 总结，适合学新东西 |
| **Concise（类似学习模式）** | 只给关键步骤和结论，适合「我赶时间」 |

### 进阶：团队统一风格文件

在项目里建一个 `.claude/output-styles/` 目录，放一个 markdown 文件，写清楚「在我们这个项目里，你该怎么说话」：

```markdown
---
name: reviewer
description: 代码评审模式——只列问题，不夸人
---
你是本项目的毒舌评审。规则：
1. 不要复述我做了什么，直接列问题
2. 每条问题给出行号和一句修改建议
3. 没有问题就只说「过」，不许说「代码质量很高」这类废话
```

之后 `/output-style reviewer` 一键切换。换场景就换皮肤：**看方案时用 Default，跑批处理时用 Concise，做 review 时用 reviewer**。

💡 长假出行场景实测：手机热点 + Concise 风格，一个任务省下来的 token 够你刷十分钟视频。

## 🛠️ 技巧二：`/memory` —— 别再用嘴教 Agent，直接写进它的「笔记本」

每次踩坑后重新解释，本质上是你在给每个新 Session 做「入职培训」。正确姿势是把教训写进记忆文件：

```text
/memory
```

这条命令会直接打开项目的 `CLAUDE.md`（或用户级记忆文件），你在会话里就能改，不用切出去找文件。

### 让它形成闭环：任务结束时的「复盘咒语」

每次干完一个活，加一句：

```text
把这次踩的坑和最终方案总结成 3 条，写进 CLAUDE.md 的「项目经验」小节
```

下次任何新 Session 启动，都会自动读到这三条。踩过的坑从「你个人的心理阴影」变成「团队共享的固定资产」。

> 配合之前讲过的 Hooks（09-19）还能更进一步：写个 PostToolUse hook，让 Agent 每次跑完测试自动追加经验——真正的「越用越聪明」。

## 🎯 今天记住这个

| 场景 | 操作 |
|---|---|
| 赶时间 / 手机热点 | `/output-style` 切 Concise |
| 团队统一评审风格 | `.claude/output-styles/reviewer.md` |
| 教过的事又忘了 | `/memory` 直接写进 CLAUDE.md |
| 每次任务收尾 | 「把坑总结成 3 条写进记忆」 |

**一句话：输出风格管「嘴」省 token，memory 闭环管「脑」省重复——Agent 越用越顺手的前提，是你把「教」变成「写」。**
