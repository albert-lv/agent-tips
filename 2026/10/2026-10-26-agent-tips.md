# 🧠 新模型三连祭：K3.1 Pro 上线了，但先别急着在老会话里切

> 2026-10-26 · 每天一个 Agent 小技巧

## 📰 今天的热点背景

上周五（10/23）Kimi Code 悄悄干了件大事：**K3.1 Pro 系列正式上线**。首个 3T-class 模型，1M token 上下文窗口，coding / 3D 创作 / 金融研究 / 长程 agent 能力全面加强。同步发布的 K3.1 Pro Highspeed 同质量下速度快 **2~3 倍**。

紧接着 v1.1.1（10/21）也铺了一波体验更新：workspace 信任提示、切模型确认、`/reload` 热加载、queued `/compact`。

听起来全是好消息对吧？但官方发布说明里藏了几个**「不看就踩」**的坑——比如直接把老会话切到 K3.1 Pro，行为可能完全不对劲。所以今天不讲虚的，就讲**新模型上线的头 24 小时该怎么操作**。

## 🛠️ 技巧一：K3.1 Pro 正确打开方式 ——「新开会话」不是建议，是规定

官方 usage recommendations 原文三条，翻译成人话：

**① 新开 session 再上车（最重要）**

> Do not switch to the new models in **existing** K3 series, K2.8 Preview, or K2.7 Code Highspeed sessions.

老会话直接切模型 = 行为不可预期 + cache 命中率暴跌。正确姿势：

```
老会话收尾 → 开新 session → 选 K3.1 Pro
```

苟在老会话里硬切，就像把柴油发动机塞进汽油车架——能打火，但别问为什么抖。

**② Thinking 不能关**

K3.1 Pro 系列**只支持 thinking 模式**（low / high / max 三档，默认 max）。手动关掉会直接吃 **400 报错**。所以如果你的配置里习惯性关了 thinking，换新模型前先恢复默认。

**③ 档位对照**

| 模型 | 可用档位 | 上下文 |
|---|---|---|
| K3.1 Pro | Plus / Moderato 及以上 | Pro / Allegretto 及以上解锁 **1M** |
| K3.1 Pro Highspeed | Pro / Allegretto 及以上 | 同上 |

想用 1M 长上下文的同学，先确认自己档位够不够——不然只能望窗兴叹。

## 🛠️ 技巧二：`/reload` + queued `/compact` —— 家规热更新，不用重启

v1.1.1 里有个容易被忽略但极其顺手的更新：

**场景还原**：你正在跑一个长任务，突然发现 AGENTS.md 里忘写了某条家规。以前要么忍着，要么重启 session 前功尽弃。现在：

```
# 改完配置文件后，直接在会话里：
/reload
```

**改完立刻生效，不打断当前任务。** 配置文件、skills、MCP 设置都支持。

配套的第二件武器是 **queued `/compact`**：

以前 agent 还在跑的时候想压缩上下文？只能干等。现在 `/compact` 可以**排队**——agent 当前 turn 跑完，自动执行压缩。长任务 + 大上下文的双重焦虑，一键缓解。

```
/agent 还在跑……
你：/compact          ← 不会打断，排进队列
→ agent turn 结束 → 自动压缩 → 继续
```

## 🎁 彩蛋：切模型确认三连

v1.1.1 还加了个「防手滑」设计：会话中途切模型时会问你三选一——

1. **新开会话**（推荐，配合上面技巧一）
2. **压缩上下文继续**（老会话想苟可以用这个，但注意 cache 会掉）
3. **直接继续**（勇士选项，行为自己扛）

这个设计本质上就是官方把「换引擎要不要重新发动」做成了显式选项。默认选第一个，准没错。

## 📌 今天记住这个

| 操作 | 命令 / 姿势 |
|---|---|
| 上 K3.1 Pro | **新开 session** 再选模型，别在老会话里硬切 |
| Thinking 开关 | K3.1 Pro **必须开**，关了报 400 |
| 改完家规想生效 | `/reload`，不用重启 |
| Agent 跑着也想压缩 | `/compact` 直接发，**自动排队** |
| 老会话舍不得丢 | 切模型时选「压缩上下文继续」，但 cache 命中率会降 |
