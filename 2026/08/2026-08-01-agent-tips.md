# 🤖 Agent Tips 2026-08-01

## 本期主题：让 Agent "记得住" —— 上下文管理的隐藏技巧

你们有没有遇到过这种情况：跟 Claude Code 聊了半天，改了一堆代码，结果它突然"失忆"了，问"你刚才说改哪来着"？

这就是经典的 **"上下文截断"** —— 不是 Agent 不想记，是窗口真的塞不下了。

---

### 💡 技巧一：给 Agent 发一份 "备忘录"

Claude Code / Kimi Code 都支持在项目根目录放配置文件（比如 `.claude/settings.local.json` 或 `.kimi/config`）。把常用的规则写进去：

- "我们项目用 2 空格缩进"
- "提交信息用中文"
- "不要动 `vendor/` 目录"

**效果：** Agent 每次启动自动加载，不用你重复唠叨。相当于给 AI 发了一份《入职手册》📘

---

### 💡 技巧二："小结一下" 比 "继续" 管用

长对话中间，主动让 Agent 做总结：

> "小结一下我们目前改了什么，下一步计划是什么"

然后**新开一个会话**，把总结贴进去当开场白。

**为什么有效：** 把 10k token 的啰嗦对话，压缩成 500 token 的精要笔记。Agent 能"记住"更多轮次的关键决策。

---

### 🎯 一句话总结

Agent 不是真健忘，是 Token 太贵（字面意思）。学会帮它做笔记，你们配合会更丝滑 🤝
