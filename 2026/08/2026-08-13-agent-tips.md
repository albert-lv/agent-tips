## 技巧一：让 Claude Code 当你的"代码考古学家"

Claude Code 有个被低估的隐藏技能：**`/` 命令搜索整个代码库的符号和定义**。

但你可能不知道的是——它搜出来的结果，**可以直接作为后续提问的上下文**。也就是说：

```
你：/search UserAuth
Claude：找到了 12 处引用...
你：把第三处的 token 验证逻辑改成 JWT，但别破坏原来的 session 回退
```

不用复制粘贴，不用手动给上下文。Claude 自己记住刚才搜到了什么，直接改。省掉你 80% 的"帮我看一下这个文件"的来回。

💡 **进阶玩法**：先 `/search` 定位，再 `/edit` 批量改。搜-改-测三步走，一个对话回合搞定。

## 技巧二：Windsurf 的 Cascade 其实会"读空气"

Windsurf 的 Cascade 有个很微妙的设定：**它会在你停顿的时候自动总结当前状态**。

这看起来是个小功能，但实际体验是——当你对着屏幕发呆、不知道怎么继续描述需求时，Cascade 会把刚才的改动和当前文件状态帮你理成一段 summary。你看着 summary，往往就突然知道自己想说什么了。

有点像那种：
> "你刚才改了 A，B 还没动，C 文件里有个 todo 标记"  
> ——然后你："哦对，我就是要把那个 todo 一起清掉。"

🎯 **使用建议**：不要急着打断它的自动总结。让它说完，你接话的时候反而更清楚自己要什么。
