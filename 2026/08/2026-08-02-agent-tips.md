> 向上、小惠早～今天分享两个最近救了我狗命的 agent 小技巧 👇

## 1️⃣ Claude Code：`/compact` — 让长会话起死回生

你和 Claude Code 聊了一个小时，改了十几个文件，突然它开始胡言乱语或者重复之前做过的事？大概率是 **上下文窗口炸了** 💀

Claude Code 藏了一个 `/compact` 命令，堪称"长聊续命丹"：

```
/compact
```

输入后，它会自动把当前会话的大量历史压缩成一段摘要，然后**在保留核心意图的前提下清空冗余上下文**。压缩完后你们可以继续聊，它还记得你要做什么，但不会再被旧消息干扰。

**什么时候用：**
- 对话超过 30-40 轮，响应开始变慢或变蠢
- Claude 开始"失忆"，重复已经做完的修改
- 你想继续同一个任务，但感觉它在"梦游"

**小彩蛋：** 压缩完后你可以说一句 "继续"，它通常能无缝接上，像什么都没发生一样。很魔幻。

## 2️⃣ Cursor Agent 模式：`@Codebase` 的全局搜索暗器

Cursor 的 Agent 模式大家都用，但有个隐藏用法很多人没注意到——在 Agent 输入框里用 `@Codebase` 配合自然语言描述，可以让 AI **主动在整个代码库里搜相关文件**，而不是只在当前打开的文件里瞎猜。

比如你说：

> "@Codebase 帮我找到所有处理用户认证的中间件，我想统一加个日志"

Cursor Agent 会：
1. 先全局搜索相关代码
2. 自己列出涉及的文件
3. 一个个改完
4. 告诉你改了哪些

比你自己切来切去翻文件再贴给 AI 快十倍。 vibe coding 的精髓就是**让 agent 自己跑腿**。
