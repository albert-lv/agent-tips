## 技巧一：Claude Code 的 `!` —— 让 Agent 自己跑命令

你是不是经常这样：

> 你：帮我查一下为什么测试挂了  
> Agent：根据代码分析，可能是这里...  
> 你：不对，你跑一下测试给我看  
> Agent：我无法直接运行命令，你可以运行 `pytest tests/foo.py` 然后贴结果给我  
> 你：*(复制粘贴)*  
> Agent：啊，我看到了，是...

来回三趟，咖啡都凉了 ☕💀

**Claude Code 有个 `!` 前缀，直接解决这个问题：**

```
你：!pytest tests/foo.py -v
```

Claude 会**自己执行命令**，看到输出，然后立刻分析。不需要你复制粘贴，不需要你当传话筒。

更妙的是——它可以**连续执行 + 修复**：

```
你：!npm run build
Agent：报错说缺少 `lodash`，我帮你装一下
Agent：!npm install lodash
Agent：再跑一次构建
Agent：!npm run build
Agent：好了，构建成功 ✅
```

🎯 **核心爽点**：Agent 从"纸上谈兵"变成"动手实干"，你从一个传话的变成发号施令的。这才是老板的感觉。

💡 **安全提醒**：Claude Code 默认会问你"要执行吗"，但你可以在设置里调整权限级别。建议保留确认，毕竟 Agent 偶尔也会手滑 😏

## 技巧二：Cursor Agent 的 Yolo 模式 —— 减少"确认点击"疲劳

Cursor 的 Agent 模式有个隐藏开关，很多人没注意到 👀

每次 Agent 要改文件、跑命令，默认都会弹个确认框让你点"Accept"。改 10 个文件点 10 次，手指都抽筋了。

**开启方式：**
- 在 Agent 对话框右上角，有个小设置图标 ⚙️
- 找到 **"Auto-run"** 或 **"Yolo mode"**（不同版本叫法不同）
- 打开后，Agent 会在它认为安全的操作（比如改代码文件、跑测试）上自动执行，不再问你

**什么时候开？**
| 场景 | 建议 |
|------|------|
| 大规模重构，要改 20+ 文件 | 开，省得点到手断 |
| 新建项目，从零搭架子 | 开，Agent 自由度越高效率越高 |
| 生产代码小修小补 | 关，谨慎为上 |
| 涉及数据库/部署命令 | 绝对关，这你懂的 |

🎯 **进阶 Combo**：Yolo 模式 + `.cursorrules` 预设规范 = Agent 又快又听话。相当于给了它驾照 + 交规，然后让它自己开。
