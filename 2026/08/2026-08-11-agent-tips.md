# 🛠️ Agent Tips — 2026-08-11

## 今日主题：Agent 的「上下文压缩」陷阱与应对

用 Claude Code / Kimi Code 时，你有没有遇到过这种情况：

> 明明文件就在项目里，Agent 就是看不见，或者只能看到半截内容。

这不是幻觉，是**上下文压缩**在搞事情。

### 💡 技巧一：给关键文件开「VIP 通道」

大多数 Agent 工具在启动时会读取项目上下文，但优先级策略不同：

- **Claude Code**: 优先读取 `.claudeignore` 反向筛选后的文件，大文件会被截断
- **Kimi Code**: 支持 `bootstrapMaxChars` 配置，默认值有时不够用
- **Cursor**: `.cursorrules` 可以强制指定必须加载的文件路径

**实战做法**：
在项目根目录放一个「必读经」清单，让 Agent 优先加载：

```json
// .cursorrules 或类似配置
{
  "always_include": [
    "README.md",
    "ARCHITECTURE.md",
    "src/core/types.ts"
  ]
}
```

### 💡 技巧二：主动「喂上下文」，别等它自己找

和 Agent 对话时，**第一条消息就贴关键代码**，比让它去翻文件更靠谱：

```
我要改的是这个函数（贴代码），目标是 xxx，
相关类型定义在这里（贴代码），
别去读其他文件，先看这两段。
```

这招叫**"上下文锚定"** —— 把 Agent 的注意力锁在你指定的地方，避免它「脑内十开页」到处翻。

### 🎯 一句话总结

Agent 不是全知全能，是**注意力有限的实习生**。你给好焦点，它输出质量翻倍。
