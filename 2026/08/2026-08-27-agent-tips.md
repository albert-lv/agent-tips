## 技巧一：Claude Code 的 `/plan` —— 先画蓝图再动手

你是不是也经历过：让 Claude Code 改个项目，它二话不说就开始删文件、移代码，等你反应过来已经晚了？

**`/plan` 命令就是专治这种"AI 冲动型施工"。**

用法超简单：
```
/plan 把用户认证模块从 Express 迁移到 Fastify
```

Claude 会先给你输出一份**执行计划**，包含：
- 具体改哪些文件
- 每步大概要做什么
- 潜在风险点

你看完觉得 OK，再打 `/approve` 让它开工；觉得不对，直接改需求。就像装修前先给你看设计图，而不是直接砸墙。

💡 **适合场景**：重构、迁移、任何你心里有底但不想被 AI  surprise 的操作。

## 技巧二：Cursor Agent 的自动终端 —— 敢不敢让它自己跑命令？

Cursor 的 Agent 模式现在支持**自动执行终端命令**了。也就是说，它不仅能写代码，还能自己 `npm install`、`git commit`、`python test.py`……

但重点来了：**别全开，开一半最香。**

在 Cursor Settings → General 里，找到 "Auto-run terminal commands"，建议这样配：
- ✅ 允许只读命令（`ls`, `cat`, `grep`, `find`）
- ❌ 拒绝写入/删除/执行类命令（`rm`, `mv`, `curl | bash`）

这样 Cursor 可以自己查环境、看日志、找文件，但真要大改之前会停下来问你。

💡 **一句话总结**：让 AI 当侦察兵，别让它当拆弹兵。
