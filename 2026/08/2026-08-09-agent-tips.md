# 🤖 今日 Agent 技巧 — 2026-08-09

> **主题：Claude Code 的「上下文折叠术」—— 让长对话不翻车**

## 1. `/clear` 不是清除，是「折叠记忆」

很多人以为 `/clear` 是把对话清空了，其实 Claude Code 的 `/clear` 更像是**把之前的对话折进抽屉里**——它还在，但不会再占用上下文窗口。

**什么时候用？**
- 聊了一个小时，话题已经从「怎么写这个函数」飘到了「周末吃啥」
- 想重新开始一个子任务，但又不想完全丢掉之前的讨论
- 上下文快满了（Claude 3.5 的 200k 也会撑不住的）

**用法超简单：**
```
/clear
```
然后直接说你的新需求，Claude 会基于之前的代码库理解继续工作，但不会被之前的闲聊带偏。

---

## 2. Kimi Code 的「@引用」—— 比复制粘贴优雅 10 倍

Kimi Code 最近支持的 `@文件` 引用，其实是一个被低估的神器。

**别这样：**
> "你看一下我那个 utils.py 里的函数..."（然后粘贴 200 行代码）

**要这样：**
> "@utils.py 里的 `parse_json` 函数帮我加个重试逻辑"

**为什么更香？**
- 上下文更干净，不会因为粘贴一大段代码把窗口挤爆
- Kimi 会自动拉取文件最新内容，不会因为"你改了我没改"而出 bug
- 多文件引用也支持：`@config.py @main.py 帮我看看这两个文件的配置是怎么传递的`

## 💡 今日小总结

| 场景 | 技巧 |
|------|------|
| 聊跑偏了 | `/clear` 折叠上下文 |
| 要引用文件 | `@文件名` 优雅引用 |

**记住：** Agent 工具不是越聊越聪明，是**越聊越需要管理上下文**。掌握这两招，你的 Agent 体验会顺滑很多。
