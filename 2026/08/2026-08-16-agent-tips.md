## 技巧一：Claude Code 的 `@` 精准投喂

你有没有经历过这种绝望：

> 你：帮我改下这个函数  
> Agent：好的，请问是哪个文件？  
> 你：`src/utils/helpers.ts` 里的 `formatDate`  
> Agent：*(改了 30 秒)*  
> Agent：改好了！我还顺手把同文件的 `parseDate` 也重构了  
> 你：*等等我没让你动那个啊* 💀

**问题不是 Agent 太积极，是你没「圈定范围」。**

Claude Code 支持 `@` 引用，直接告诉它"就看这些，别的别碰"：

```
你：@src/utils/helpers.ts 里的 formatDate，改成支持时区参数
```

更细粒度：

```
你：@formatDate 函数加 timezone 参数
```

甚至直接引用符号（函数、类、变量）：

```
你：@UserService.getProfile 这个接口，把返回字段里的 email 脱敏
```

🎯 **核心爽点**：Agent 不再"地毯式搜索"，而是**精确打击**。省时间，少误伤，不用收拾烂摊子。

💡 **进阶玩法**：
- `@src/` —— 引用整个目录，Agent 会把这个目录当上下文
- `@package.json` —— 引用配置文件，Agent 自动读取依赖和脚本
- `@#123` —— 引用 PR 或 Issue（如果你连了 GitHub）

## 技巧二：Cursor 的 `Ctrl+K` 行内编辑 —— 不改全局，只动这一块

Cursor 有个被低估的神器：**Ctrl+K（Cmd+K）行内编辑**。

不是打开 Chat 面板唠半天，而是**选中几行代码，直接下指令**：

1. 选中你想改的代码块
2. 按 `Ctrl+K`
3. 输入指令：`"改成异步的"`、`"加错误处理"`、`"用 map 替代 forEach"`
4. 回车，Agent 只改你选中的部分

**和 Chat 模式的区别：**

| 模式 | 适合场景 | Agent 的视野 |
|------|---------|-------------|
| Chat | 大改动、跨文件、需要讨论 | 整个项目或你提供的上下文 |
| Ctrl+K 行内 | 小改动、局部重构、快速调整 | 只看你选中的代码 + 少量周围上下文 |

🎯 **什么时候用行内？**
- "这 5 行加个 try-catch"
- "把这个函数改成箭头函数"
- "这段 SQL 加个索引提示"
- "变量名改得有意义点"

**不用开 Chat、不用等 Agent 理解整个项目、不用担心它顺手改到别的文件。**

💡 **Combo 技巧**：行内编辑后，如果涉及其他文件，再切到 Chat 说："刚才改的 `fetchUser` 现在返回格式变了，去更新一下调用方"。精准 + 连贯 = 丝滑。
