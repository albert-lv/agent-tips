# 2026-08-22 Agent Tips

## Claude Code 的「反问模式」—— 让 AI 帮你发现你忘了问什么

Claude Code 有个被严重低估的隐藏技巧：在指令末尾加一句 **"What am I missing?"** 或者中文的 **"还有什么我没考虑到的吗？"**

效果很离谱。Claude 会从你描述的需求里，找出你下意识忽略掉的边界情况、潜在风险、或者更优路径。比如你说"帮我写个爬虫抓这个网站"，它会反问：
- 对方有没有 robots.txt 限制？
- 需要处理反爬吗？
- 数据量多大，要不要考虑增量抓取？
- 存数据库还是文件？

相当于白嫖一个**需求评审环节**，而且是你不尴尬的那种——因为是 AI 在问，不是你老板。

**用法：** 任何复杂任务问完后，顺手丢一句 "what else should I consider?"，经常能救你于返工火海。

## Kimi Code 的上下文压缩：别让系统把你的文件吃了

如果你用 Kimi Code 处理大项目，可能会遇到一种诡异情况：你明明在文件 A 里改了东西，AI 却说"没看到你改啊"。

不是幻觉，是**上下文压缩**在搞事情。当项目文件太多，Kimi 会压缩或截断部分文件内容来 fit 进上下文窗口，有时候会把你的最新改动"压掉"。

**应对策略：**
1. **主动引用** - 改完关键文件后，显式告诉 AI "我刚更新了 src/config.ts，你看一下"
2. **分块处理** - 大重构拆成几轮对话，每轮聚焦一个模块
3. **确认回显** - 让 AI 复述它看到的文件内容，确认没丢

这招对其他 agent 工具也适用——上下文不是无限的，**别以为 AI 真的"看过"了你所有文件**。

---

> 💡 **今日小抄**：复杂任务结尾加一句反问，能省一半返工；大项目里别信 AI 真的看完了所有文件，主动确认。
