# 2026-08-06 Agent Tips

## 今日主题：上下文压缩 ≠ 信息丢失，学会和 Agent "打哑谜"

### 1. Claude Code：`/clear` 不是清屏，是给大脑做深呼吸

很多人都知道 Claude Code 有个 `/clear` 命令，但不少人以为它只是清屏——**大误**。

实际上 `/clear` 是把当前会话的上下文做了一次**压缩归档**。好处是：
- 解决那种聊着聊着 Agent 开始"胡言乱语"的情况
- 让后续对话轻装上阵，响应速度明显变快
- 但注意：压缩后细节可能会丢，重要结论建议手动保存

**实用场景**：当你感觉 Claude Code 开始"疲劳驾驶"（比如反复问同一个问题、开始自我矛盾），来一发 `/clear`，相当于给它灌了杯咖啡 ☕

> 💡 **进阶玩法**：配合 `@file` 引用把核心文件重新丢给它，相当于快速重建上下文，比从头开始效率高得多。

### 2. Kimi Code：多文件编辑时，用 `// TODO:` 当暗号

Kimi Code 处理多文件项目时有个隐藏 buff：如果你在代码里留 `// TODO: 让Kimi帮我xxx` 这种注释，它下次扫描代码时会**主动认领任务**。

这比你在聊天框里喊 "帮我改一下那个文件" 高效多了——
- Agent 自己看到 TODO，自己定位，自己改
- 你甚至可以在多个文件里埋 TODO，让它批量处理
- 改完它还会把 TODO 删掉，强迫症狂喜

**一句话总结**：把指令写进代码，让 Agent 自己巡逻捡任务，你就是那个运筹帷幄的 PM 🎯
