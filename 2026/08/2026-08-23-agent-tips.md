# 🕰️ Claude Code 的时光机：/undo 不只是撤销，是你的安全网

> 2026-08-23 | 每日 Agent 技巧

大家都知道 Claude Code 能写代码，但很多人不知道它其实自带**时光机功能**——玩脱了能一键回退，想大胆重构也不再慌。

---

## 技巧 1：/undo 是真正的「项目级撤销」

不是只能撤回上一句对话。

Claude Code 的 `/undo` 会**回滚整个代码库到上一步操作之前的状态**——包括所有被修改、创建、删除的文件。

**什么时候用：**
- 让 Claude 重构了 20 个文件，跑完测试发现全炸了 → `/undo`，世界安静了
- 想试试某个大胆方案，但又怕把现有逻辑搞乱 → 先试，不行就 `/undo`
- 误删了重要文件 → `/undo` 能救回来

**用法超简单：**
```
/undo
```

然后 Claude 会问你要回退到哪一步，选对应的数字就行。

---

## 技巧 2：手动打 Checkpoint，大胆做实验

Claude Code 会自动在某些关键点创建 checkpoint，但你也可以**手动打标记**：

```
/checkpoint
```

给当前状态拍个快照，然后你就可以放心让 Claude 去折腾了。

**实战场景：**

> "帮我把这个 React 类组件全部改成 Hooks 写法"
> 
> — 先 `/checkpoint` 拍个照
> — 让 Claude 开工
> — 改完跑测试，挂了？`/undo` 回到拍照点
> — 测试过了？`/checkpoint` 再拍一张，继续下一步

这就像游戏里的**存档点**，让你在复杂重构里也能有节奏地推进，而不是一次性赌一把大的。

---

## 💡 一句话总结

> `/undo` 是后悔药，`/checkpoint` 是存档点。两者配合，Claude Code 就从「聊天写代码」升级成了「有版本控制的结对编程」。

下次想大胆重构的时候，别怂，先 `/checkpoint`，然后放手干 💪
