# 🛠️ Agent 技巧 · 2026-08-14

> 今天聊两个能让你的 AI Agent 从"人工智障"变回"人工智能"的小技巧——**防失忆**和**少废话**。

---

## 技巧一：给 Agent 递个小抄（防失忆）

你们有没有这种感觉：跟 Agent 聊久了，它突然开始"失忆"？

> "你刚才不是让我改 A 吗？我怎么把 B 删了？"

这就是经典的 **上下文窗口 (Context Window) 爆炸** 💥 Agent 本质上是个高级金鱼，记忆满了就把最早的对话冲进马桶 🚽

**怎么治？**

- **Claude Code / Kimi Code 用户**：对话到一半，可以丢一句 `summarize our plan and current progress so far`，让它自己生成个摘要。相当于给金鱼递个小抄 📋
- **通用解法**：如果发现 Agent 开始胡言乱语、重复犯错，别跟它硬刚，直接新开一个对话，把核心目标和当前进度 paste 进去。这叫 **Session 重启疗法**。

💡 **向上专属 callback**：你之前不是遇到过 USER.md 被截断的情况吗？就是这种上下文压缩机制在作怪。现在知道咋治了吧 😏

## 技巧二：Cursor 的 `.cursorrules`（少废话）

Cursor 用户看过来，别每次打开项目都从零开始调教 AI，累不累啊 😩

去项目根目录搞一个 `.cursorrules` 文件，把你们团队的"家规"写进去：

```text
- 使用 TypeScript，严格模式
- 优先使用 async/await，禁止回调地狱
- 我们用 Bun 而不是 npm，别生成错命令
- 组件命名用大驼峰，工具函数用 camelCase
```

Agent 每次开局会自动读这个文件，相当于给它塞了本《员工手册》。省得你每次都当 HR 复读机 📢

🎯 **进阶玩法**：可以按项目写不同的 rules，甚至按目录嵌套。前端一套规则，后端一套规则，互不干扰。
