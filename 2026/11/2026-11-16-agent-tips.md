> 上周四（11/13）Google 甩出 Gemini 4 Hydrogen——不是冲榜的旗舰，而是专门给 agentic 工作流跑量的「快手模型」，四档思考深度、全 1M 上下文统一价 $1.50/$7.50。同一天 Antigravity 上线 Orchestrator：同一会话里 Carbon 出图纸、Hydrogen 盖房子，卡壳自动交回重想，配额省 24%、速度快 19%。**「该动脑时动脑、该动手时动手」从口号变成了产品功能**——今天讲怎么不等 Google，手动把这个套路跑起来。

## 📰 今日热点背景

- **Gemini 4 Hydrogen（11/13）**：定位日常 coding + agentic 执行的快模型。默认 high 档在 Artificial Analysis 智能指数拿 51 分（压过自家更贵的 Argon 50），xhigh 档 54；Terminal-Bench 4.1 从 3.8 Flash 的 18.2% 跳到 57%，速度快 2.5 倍，虚构声明降 5 倍。价格最扎眼：**$1.50/$7.50 全 100 万上下文无阶梯**——大批量读写不再越读越贵。
- **Antigravity Orchestrator（11/13）**：同一会话内 Carbon ↔ Hydrogen 动态切换。典型节奏：Carbon 只读勘察 + 出计划 → Hydrogen 写代码、改包、跑测试 → 测试挂了交回 Carbon 修计划 → 再交回 Hydrogen 施工。官方数字：接近 Carbon 的任务成功率，配额 -24%，速度 +19%。目前 Orchestrator 全量限 Ultra 订阅，Pro 只有 Argon 版。
- **Codex CLI 周末双更（0.168 / 0.169，11/13）**：多 chat 标签页并行 + 侧边会话面板 + 任务搜索 + 自定义模型 provider（Fable 5.2 也已进 Codex 模型列表）+ 语音录入。

## 技巧一：手动复刻 Orchestrator——每一步只问一个问题：「这在动脑，还是在动手？」

Orchestrator 的核心不新鲜，就是 9-23 那篇「模型编队」的自动挡。但它的数字给手动编队补上了官方背书：跨档混编能省 24% 配额、快 19%，成功率还不掉。手动版今天就能搭，四步：

1. **出图纸（旗舰模型）**：新开会话，只让它读代码、出方案——「先别改代码，给我一份改动计划：动哪些文件、按什么顺序、怎么验证」。Plan Mode 天然干这个（10-13 讲过）。
2. **盖房子（快手模型）**：拿着方案开工——新开会话或 `/model` 切档（上下文不丢，11-14 验证过），按图施工：改文件、跑测试、修 lint。
3. **验收（旗舰模型）**：diff 出来了切回旗舰做终审——逻辑对不对、有没有改出隐藏副作用。
4. **卡壳交回**：施工模型连续两次修不好同一个错，别硬磨——把报错交回旗舰重新规划，这正是 Orchestrator 的「hand back」节奏。

各家的「施工队」人选：

- **Claude Code**：Fable 出图纸、Sonnet 5.5 施工、Haiku 5.5 跑腿（子代理 `model:` 字段或 `ANTHROPIC_SMALL_FAST_MODEL`）；
- **Kimi Code**：主会话旗舰 + `[secondary_model]` 模型池外包杂活（注意 2.5.0 起主模型要显式进池，别用隐式 primary）；
- **API 党新备胎**：Hydrogen $1.50/$7.50 全 1M 无阶梯，比 Sonnet 5.5（$2/$10）还便宜一截，批量读仓库场景值得一试。

一个容易忽略的点：官方说 Hydrogen 这类执行模型「减少越权 81%、减少任务走捷径 12 倍」——**施工阶段的 agent 越聪明越爱自由发挥**，快模型反而更守规矩。所以「让快手干体力活」不只是省钱，还是质量控制。

## 技巧二：Codex 变身「多开浏览器」——0.168 的多标签并行 + 任务搜索

如果你同时推进多条线（主力会话跑着长任务，还想顺手问个别的事），Codex 0.168 / 0.169 这波更新正好治「排队焦虑」：

- **多 chat 标签页**：一个窗口开多个并行会话，和浏览器标签一样切——长任务在标签 A 跑，标签 B 开个新问答不用打断（Claude Code 分身术 08-21 讲过，Codex 终于跟上）；
- **侧边会话面板（side sessions）**：后台任务收进侧边栏，主对话不被过程输出刷屏；
- **任务搜索**：翻历史任务不用滚——按关键词搜，上周五干了一半的活，周一早晨秒找回（本周刚需）；
- **自定义模型 provider**：config 里能接自己的模型服务，Fable 5.2 也已进 Codex 模型列表——一个工具里跨家用模型，又少一道切换成本。

顺手对齐：Kimi Code 的 `/import-sessions`（10-28 的 2.4.0）能从 Claude Code / Codex 导入近 15/30 天会话——工具越换越勤的年代，会话资产跟着人走，比锁死在某一家重要。
