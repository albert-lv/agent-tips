# 2026-11-23 —「1M 油箱也会见底 + 合盖不等于下班」：Fable 5.2 长任务得配"记账员"，Kimi Code 桌面端 1.4.0 让活留在服务器上跑

> **Claude Fable 5.2** 发布两周，测评越拆越细，上周的数据拆出一个扎心真相：1M 上下文不是免死金牌——同一模型，提不提醒它"看油表"，成绩从烧穿率 68% 到 91.6%。另一边，**Kimi Code 桌面端 1.4.0**（11/19）上了个打工人刚需：SSH 远程项目，本机离线后任务继续跑。今天讲两个立刻能用的：怎么给 Fable 长任务配上"记账员"，以及怎么让笔记本合盖不再等于任务暴毙。

## 技巧一：Fable 5.2 跑长任务 —— 1M 上下文也得配"记账员"

先说结论：Fable 5.2 自己**看不见油表**。模型的上下文窗口对它来说像没有油量报警的车——你不提醒，它就一路狂飙，68% 的概率开到没油抛锚（任务烂尾、中途失忆、重复劳动）。ProgramBench 那组对比数据说明：**同一个模型，只差一句"每步告诉它还剩多少"，成绩从烂尾 68% 变成 91.6%**。

做法很简单，在 `CLAUDE.md`（或长任务 prompt 开头）加一条"长任务纪律"：

```markdown
长任务纪律：
- 每完成一个阶段，先估算当前会话已消耗的上下文比例；
- 判断已用超过 60% 时，先把中间结论、已修改文件清单、待办状态
  追加写入 .claude/progress.md，再继续下一阶段；
- 新会话恢复工作时，先读 .claude/progress.md。
```

三条实战要点：

1. **60% 是动手点，不是 90%**。等上下文真见底再总结，压缩质量和剩余空间都不够；60% 时模型状态还完整，落盘的笔记最值钱。
2. **别把 Fable 当日常默认**。它是狙击枪不是通勤车——$26.54/任务的均价（Opus 5.5 max 档 $10.04），官方自己都说日常编程优先 Opus 5.5。Fable 留给"卡了两小时没头绪的架构题"和"要一口气跑几小时的自治任务"。
3. **版本门槛**：Claude Code 需要 **2.1.321+** 才能在模型列表里选到 Fable 5.2，脚本党直接 `claude --model claude-fable-5-2`。API 价 $8/$40（比上代降 20%），Fast Mode 2.5 倍速但价格翻倍，非紧急别开。

## 技巧二：Kimi Code 桌面端 1.4.0 —— 任务挂服务器，本机随便断

场景太经典了：笔记本上挂一个三小时的批量重构/全量测试，中途合上盖子、断网、甚至没电关机——任务当场暴毙，回来从头再来。1.4.0 的解法：**SSH 远程项目**，Agent 直接跑在远程主机上，本机只是个"显示屏"，离线后任务继续跑，重连接着看。

上手路径：

1. 项目设置里添加 **SSH 主机**，各主机独立登录凭证（CLI 2.7.0 同天也跟进了项目级 SSH 主机配置，还能给不同主机复制自定义模型提供商）；
2. 把耗时任务丢给远程项目的 Agent；
3. 本机关机/合盖/断网随便折腾，重连后会话原样恢复。

组合拳更香：1.1.0 就有"远程控制"（设置里开启后，用链接或二维码从**其他设备**控制本机 Agent）。现在叠上 SSH 远程项目——白天在办公室把重构挂上服务器，地铁上用手机看一眼进度、插句"那个目录别动"，活全程没停过。

顺手升级的理由：CLI **2.7.2**（11/20）修掉了"发送后草稿的思考强度被重置成模型默认值"的 bug——如果你上周发现思考档位设置老是自己跳回默认，升级到 2.7.2 即修。2.7.1 还修了恢复含插话会话后按轮次建分支失败的问题。

## 🥚 彩蛋：三个小但香的更新

- **Claude Code `/status` 会点名"装病"的配置文件了**（11/17 版）：agent / skill / command / output style 的 JSON 文件写错一个逗号，以前的下场是**无声失效**——skill 突然不触发，你以为是 prompt 没写好。现在 `/status` 直接列出损坏文件清单，旁边还有 Marketplace auto-update 行显示插件自动更新状态（11/20 版）。工具神秘失灵时，先去 `/status` 看一眼。
- **`/mcp` 新增 "Server message" 行**（11/19 版）：MCP server 主动推过来的 JSON-RPC 报错（比如 server 说"你传的参数我拒了"）以前会神秘失踪，现在直接显示在服务器详情里——MCP 排障少猜一半。
- **Fable 5.2 的"保镖"机制**：它带网络安全和生物领域防护，相关提问会被拦截（官方口径误拦截比 5.1 减少约 55%）。API 用户注意按文档自行配置 fallback，别在日志里看到模型突然"降级"以为穿越了。
