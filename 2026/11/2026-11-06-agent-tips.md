## 技巧一：会算这笔账，才知道 Hosted Agents 值不值

看到「托管智能体」很多人第一反应是「又一个让我花钱的云服务」。来算笔账：

**定价公式 = 沙箱时长 × ¥0.072/小时 + 模型推理费 + 插件调用费**

关键就在第一项：让一个 Agent **全天无休跑满一个月**，沙箱成本是 720 × 0.072 ≈ **¥52**。五十二块钱，一个月。

对比一下自建方案的成本：一台能跑 Agent 的 VPS（¥50-100/月）+ 自己写沙箱隔离、会话持久化、断线恢复、工具调用层（几个月工程量）+ 后续持续维护。Hosted Agents 把后面两块直接归零，你只需要写业务逻辑、接工具。

**什么时候该用它？**

- ✅ 任务是**长程/异步**的：7×24 监控、定时晨报、持仓盯盘——这类任务本地电脑不可能一直开着
- ✅ 你**不想维护基础设施**：沙箱、故障恢复、重试调度平台全包了
- ❌ 任务是短平快的交互式编码——这种还是 Kimi Code CLI / Desktop 顺手，别为「托管」付沙箱时长费

另外一个容易被忽略的能力：**Kimi Inference Hook**。它能在每次模型推理**之前**检查输入和工具返回内容，把隐私/敏感数据拦在模型调用之前——规则由企业自己定义。对数据敏感的团队，这是「Agent 上线」和「Agent 敢上线」的区别。

## 技巧二：Claude 用户注意了——11/10 你的界面可能要变

Claude Cowork 的 changelog 里埋了个 breaking change，**11 月 10 日（下周一）生效**：

> 未设置的 `desktopHome` 将被读作 `standard`——Unified Claude 启动时默认打开 Cowork 界面，即使你之前设了 `coworkTabEnabled: false`。

翻译成人话：如果你靠配置把 Cowork 标签藏起来了，4 天后它会自己回来。今天就能做两件事：

1. **检查你的配置**：如果你确实不想要 Cowork 默认界面，趁这几天显式把 `desktopHome` 设成你原来的值，别等升级后愣住。
2. **顺便看看新 Monitor 工具**：Code sessions 现在带 Monitor 了——Agent 跑长任务时可以挂着看实时进展，配合 2.1.317 的用量报告（昨天讲过），「任务进度 + 成本」两条线都透明了。

还有个小变化值得点头：**存在本机的供应商 API Key 将加密存储**（下次启动时自动迁移加密）。版本低于 4.29 的客户端读不了加密后的 key——所以如果回滚旧版本，要重新输入一次。不算麻烦，但知道这回事，遇到「key 失效」提示就不会懵。
