## 技巧一：政策 8 问自查 —— 10 分钟过完，别等政策来找你

做产品 / 接 API / 碰合规的同学，今天花 10 分钟对照官方 AUP 原文过一遍。按与你产品的相关度排，最容易踩的排前面：

1. **你在转售或代理 Claude 吗？** 这次写得最狠的一条：禁止未经授权转售 / 代理。来路不明的中转 key、拼车账号、代购渠道的风险指数从此**写进了政策正文**而不是灰色地带。普通用户视角：你手里那把「别人给的 key」，出借人本身可能已违规——别在关键路径上依赖它。
2. **产品生成或分发面向公众的内容吗？** 检查是否有隐藏发布者、虚假账号放大、批量内容农场——新增的「欺骗性活动」专节就是冲着这个来的。
3. **有追踪 / 找人 / 位置功能吗？** 需要明确同意；执法类场景不要让模型决定调查或起诉对象。
4. **影响健康、法律、金融、就业、基本服务吗？** 必须有合格的人复核并可改动结果，且向用户披露用了 AI。
5. **连接了硬件 / 让模型执行物理动作吗？** 人可实时观察 + 急停，Claude 断开后设备要进入安全状态。
6. **碰选举政治内容吗？** 这次反而收窄了，主要是防冒充和虚假信息。
7. **公司注册地 / 总部 / 控股结构在支持地区吗？** 政策把「人不在支持地区」「公司注册地不在」「被不支持地区实体控股」三种情形都写明了。
8. **有没有长期无目的辱骂模型？** 这条对正经用户基本无影响，但它是本次传播度最高的一条——连官方都预设了会有人跟模型对骂，某种意义上是 LLM 走向大众的里程碑（？）

**执行建议**：把检查结论 + 负责人 + 日期写进内部文档。合规这件事，「留痕」本身就是合规的一部分。

**更深一层**：把 11/8 的 Cursor 断供和今天的政策更新放在一起看——**模型访问权正在同时被「商业博弈」和「合规框架」双向收紧**。昨天是合同条款被援引，今天是转售条款入正文。长期依赖单一供应商 key 的架构，以后要同时扛住两种风险。这和多模型阵型（Cursor 押注多模型、GitHub 推 Fusion）是同一个趋势的两面：**模型可移植性不再是优化项，是保险项**。

## 技巧二：KYC 风暴自救 4 条 —— 稳住，别自己把自己风控了

11/5 起大量用户反馈：Pro 开通 / 续费 / 新注册被弹 KYC。恐慌是最没必要的反应，但也别头铁：

1. **千万别反复重试**。代购渠道已经因为「频繁失败的支付和验证记录本身增加账号风险」而暂停了充值——每次失败都在给风控喂数据。被弹了，就按流程走完；走不通，隔几天再说。
2. **备齐正确材料**：实体证件原件 + 现场自拍。复印件、电子证件、截图都不收——看到要求「上传证件照」的假验证页面要警惕，官方入口认准 anthropic.com / claude.ai 域名，验证服务商是 Persona。
3. **高频自动化调用是触发点之一**（社区观察，非官方确认）：CI / cron 里挂个人 key 猛跑的同学注意——把机器流量和用户流量分开，企业组织走官方的 service account 和 Admin API（11/5 Admin API 还新增了「一键登出全端成员」的 beta，管账号的正确姿势都在往企业侧收）。
4. **分场景备号**：工作流里把「关键路径」和「随便试试」分开——需要稳定在线的自动化用走企业流程的正式 key；薅羊毛性质的试用号被风控了也不心疼。别把所有鸡蛋放在一个会被 Persona 随机点名的篮子里。

## 🥚 彩蛋：GitHub Universe 的 Copilot Fusion —— 一个任务，多个模型分段接力

上周 GitHub Universe 被 Cursor 断供和 Anthropic 政策两条大新闻盖住了风头，但对工具选型的人它很重要：**Copilot Fusion** 做多模型路由——一个编码任务的不同环节（读代码 / 改代码 / 写测试 / review）可以自动分给不同模型和 harness；**Copilot Projects** 做多 repo 编排，issue → plan → 多 agent 并行 → merge。

加上 11/8 说的 Cursor 多模型阵型、Bolt.new 上廉价 agent 模式 Forge、OpenCode 的 BYOK 万能转换头——**「一个 frontend 绑死一个模型」的时代正式结束了**。对我们自己的项目（nano-agent / nano-symphony 这种 agent 基建），启示很直接：rollout provider 这层抽象（Arena 正在做的 veRL adapter）价值会继续放大，因为上游模型的可替换性已经是平台级共识，不是小众洁癖。
