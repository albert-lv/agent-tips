# 🤖 Agent Tips · 2026-11-27

## 今日热点

本周 Claude Code 连发四个版本（2.1.321 → 2.1.328），其中最炸的一个是 **Code Mode**：从 11 月 12 日的 2.1.323 开始，Claude Code 加入了一个实验性模式——Claude 不再一个个"问你要不要执行工具"，而是直接**写 JavaScript 代码来调用自己的工具**。同时，Claude Fable 5.2（1M 上下文，$8/$40 每 Mtok）已经成为默认 Fable 模型。

---

## 🎯 技巧一：Code Mode —— 让 Claude "写代码调自己"

**这是什么：** 传统模式下，Claude 每次想读文件、跑命令，都要发起一次工具调用、等你确认。Code Mode 下，Claude 生成一段 JS 脚本，里面编排好"先读 A 文件 → 再 grep → 再改 B 文件"的完整流程，一次执行。

**怎么开：** 目前还是实验性 opt-in，参考官方文档 `code.claude.com/docs/en/code-mode` 打开。注意：
- 11 月 16 日的 2.1.326 已经支持 **Code Mode + Agent Teams 同时开启**，团队模式下默认进 Code Mode
- 也支持在开启 OpenTelemetry 的同时使用，每个工具调用都会发出 trace 事件

**为什么值得试：** 多步骤任务（比如"重构这个模块并更新所有引用"）的延迟和打断次数会明显下降。Claude 从"一步一步问"变成"写个剧本一次跑完"。

**⚠️ 注意：** 它是实验功能，权限控制逻辑还在迭代。用在重要仓库前，建议先在沙盒项目里跑几天。

## 🎯 技巧二：Fable 5.2 的 1M 上下文 —— 整库塞进去的正确姿势

11 月 9 日起，`fable` 别名默认指向 **Fable 5.2**：1M token 上下文，输入 $8 / 输出 $40 每 Mtok，缓存读取只要 $0.20。

**实用建议：**
- 1M 上下文最适合"**一次性理解大型遗留代码库**"的场景：把整库核心文件塞进去做架构分析、跨模块依赖梳理，比逐文件 RAG 检索更准
- **但别把 1M 当日常模式用**：定价摆在那里，日常编码还是用默认模型，只在"需要全局视野"的任务切 Fable
- 用 `/model` 可以看到当前模型；如果显示 "Requires usage credits"，说明这笔账要走 usage credits 而非订阅额度——先看清再跑长任务
