## 💡 内容特色

### 1. 技巧 = 「原来还能这么用」

不是文档翻译，是让你拍大腿的发现：

- **Claude Code `/search`** — 搜完结果直接当上下文改代码，不用复制粘贴
- **Cursor `.cursorrules`** — 写一次项目规范，省掉 500 次 "请用 TypeScript"
- **`!` 前缀** — Agent 自己执行 shell 命令，你从传话筒变指挥官

示例（08-14 — 防失忆）：
> 💬 **你**：Claude 开始胡言乱语了
>
> 🎯 **你**：`summarize our plan` → 拿到摘要 → 新开 Session paste 进去 → 问题解决

### 2. 每篇 = 5 分钟读完 + 立即可用

- **场景开头** — "你是不是经常这样..."（代入感）
- **技巧主体** — 命令/设置/操作步骤
- **一句话总结表** — 看完记住核心，不用回头翻

### 3. 多工具交叉覆盖

一个技巧往往能跨工具复用：

| 概念 | Claude Code | Cursor | Kimi Code |
|---|---|---|---|
| 项目规范 | `Claude.md` | `.cursorrules` | 类似配置 |
| 防失忆 | `/compact` | — | `summarize` |
| 自动执行 | `!` 前缀 | Yolo/Auto-run | — |
